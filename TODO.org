* DONE need to add a "snap" feature
If, due to imprecision, a vertex ends up eerily close to another, but not exactly equal, I'd like to "snap" them together.  I had a model that traced some wire curves where an expected intersection didn't actually occur.  

There is a conservative default distance of lambda/1000000 for floating-point
drift. The user can override it with the ~(model snaplen METERS)~ pair; zero
disables proximity snapping while retaining exact vertex merging.
